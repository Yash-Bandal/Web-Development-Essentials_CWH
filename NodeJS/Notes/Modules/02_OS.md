# OS Module

The `os` module in Node.js provides utilities to get information about the operating system.

### Importing

```js
const os = require('os');
```

<br>


### 1. System Info

#### Hostname

```js
console.log(os.hostname());
```

#### Platform

```js
console.log(os.platform()); // 'linux', 'win32', 'darwin', etc.
```

#### Architecture

```js
console.log(os.arch()); // 'x64', 'arm', etc.
```

#### OS Type

```js
console.log(os.type()); // 'Linux', 'Windows_NT', etc.
```

#### OS Release Version

```js
console.log(os.release());
```

<br>


### 2. CPU Info

#### CPU Cores Info

```js
console.log(os.cpus());
```

#### Number of Cores

```js
console.log(os.cpus().length);
```

<br>


### 3. Memory Info

#### Total System Memory

```js
console.log(os.totalmem()); // in bytes
```

#### Free System Memory

```js
console.log(os.freemem());
```

<br>


### 4. Uptime

```js
console.log(os.uptime()); // in seconds

```

<br>


### 5. User Info

```js
console.log(os.userInfo());
```

<br>


### 6. Home Directory

```js
console.log(os.homedir());
```

<br>


### 7. Network Interfaces

```js
console.log(os.networkInterfaces());
```

This is useful for getting IP addresses and network configuration.

<br>


### Conclusion

| Feature            | Method                   | Description               |
| ------------------ | ------------------------ | ------------------------- |
| Hostname           | `os.hostname()`          | System host name          |
| Platform           | `os.platform()`          | OS platform               |
| Architecture       | `os.arch()`              | CPU architecture          |
| CPUs               | `os.cpus()`              | CPU details               |
| Total Memory       | `os.totalmem()`          | Total RAM in bytes        |
| Free Memory        | `os.freemem()`           | Free RAM in bytes         |
| Uptime             | `os.uptime()`            | System uptime in seconds  |
| User Info          | `os.userInfo()`          | Current user details      |
| Home Directory     | `os.homedir()`           | User’s home directory     |
| Network Interfaces | `os.networkInterfaces()` | Network interface details |
