## Library vs Framework
1. A framework is a set of pre-written code that provides a structure for developing software applications.
2. A library, on the other hand, is a collection of pre-written code that can be used to perform specific tasks
3. A framework controls the application's flow, while a library is called upon by the application,
4. Framework contains library
