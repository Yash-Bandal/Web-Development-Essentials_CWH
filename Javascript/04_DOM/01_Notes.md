## 1. Introduction to the DOM

### 1.1 What is the DOM?

* DOM stands for **Document Object Model**.
* It is a programming interface for HTML and XML documents.
* The DOM represents the page as a **tree structure** where each node is an object representing a part of the document.

### 1.2 Why is the DOM important?

* JavaScript can **interact with and manipulate** the content, structure, and style of a webpage using the DOM.
* It allows developers to build **dynamic, interactive websites**.

### 1.3 DOM Tree Structure

* The DOM tree is a hierarchical structure of nodes:

  * **Document**: Root node
  * **Element nodes**: HTML elements like `<div>`, `<p>`, `<a>`
  * **Text nodes**: Actual text within elements
  * **Attribute nodes**: Attributes like `class`, `id`, `src`
  * **Comment nodes**: HTML comments

Example structure:

```html
<html>
  <body>
    <h1>Hello</h1>
    <p>This is a paragraph</p>
  </body>
</html>
```

Tree representation:

```
Document
 └── html
     └── body
         ├── h1
         │   └── "Hello"
         └── p
             └── "This is a paragraph"
```

### 1.4 DOM vs HTML

| HTML              | DOM                           |
| ----------------- | ----------------------------- |
| Static markup     | Dynamic object representation |
| Written by devs   | Generated by browser          |
| Cannot be changed | Can be manipulated with JS    |

## 2. Accessing Elements

### 2.1 Methods to Access Elements

JavaScript provides several methods to access elements in the DOM:

#### 2.1.1 `getElementById()`

* Returns a single element with the specified ID.
* Fast and commonly used when working with unique elements.

```js
const title = document.getElementById("main-title");
```

#### 2.1.2 `getElementsByClassName()`

* Returns a live HTMLCollection of all elements with the specified class name.

```js
const items = document.getElementsByClassName("list-item");
```

#### 2.1.3 `getElementsByTagName()`

* Returns a live HTMLCollection of all elements with the specified tag name.

```js
const paragraphs = document.getElementsByTagName("p");
```

#### 2.1.4 `querySelector()`

* Returns the **first** element that matches a CSS selector.
* Useful for more complex queries.

```js
const firstItem = document.querySelector(".list-item");
```

#### 2.1.5 `querySelectorAll()`

* Returns a **static NodeList** of all elements matching the CSS selector.

```js
const allItems = document.querySelectorAll(".list-item");
```

### 2.2 Difference Between Live and Static Collections

| Method                 | Returns        | Live or Static |
| ---------------------- | -------------- | -------------- |
| getElementsByClassName | HTMLCollection | Live           |
| getElementsByTagName   | HTMLCollection | Live           |
| querySelectorAll       | NodeList       | Static         |

### 2.3 Looping Through Collections

Since `HTMLCollection` and `NodeList` are not true arrays, use `for...of` or convert to array:

```js
// Using for...of
for (const item of allItems) {
  console.log(item.textContent);
}

// Converting to array
Array.from(allItems).forEach(item => console.log(item.textContent));
```

## 3. DOM Properties & Content

### 3.1 Reading and Modifying Element Content

#### `innerHTML`

* Gets or sets the HTML content of an element (includes tags).

```js
const div = document.getElementById("box");
div.innerHTML = "<p>Updated paragraph</p>";
```

#### `textContent`

* Gets or sets only the text content, ignoring HTML tags.

```js
div.textContent = "Just plain text";
```

#### `innerText`

* Similar to `textContent`, but considers styling and hidden elements.

```js
div.innerText = "Visible text only";
```

### 3.2 Accessing and Modifying Form Values

#### `value`

* Used to get/set values of form elements like inputs.

```js
const input = document.getElementById("username");
input.value = "newuser";
```

### 3.3 Working with Attributes

#### `getAttribute()` and `setAttribute()`

```js
const link = document.querySelector("a");
link.getAttribute("href");
link.setAttribute("target", "_blank");
```

### 3.4 Manipulating Class and ID

#### `className`

* Gets/sets all class names as one string.

```js
div.className = "box highlight";
```

#### `id`

* Gets/sets the ID of the element.

```js
div.id = "new-id";
```

#### `classList`

* Modern and flexible way to manage classes.

```js
div.classList.add("visible");
div.classList.remove("hidden");
div.classList.toggle("active");
```

### 3.5 Inline Style Manipulation

#### `style` Property

* Allows you to directly apply CSS styles.

```js
div.style.color = "blue";
div.style.backgroundColor = "lightgray";
```

## 4. Modifying Elements

### 4.1 Changing Text and HTML Content

#### `innerHTML`

* Replaces or retrieves the full HTML inside an element.

```js
div.innerHTML = "<strong>New content</strong>";
```

#### `textContent`

* Changes or gets the plain text inside an element.

```js
div.textContent = "Updated text only";
```

#### `innerText`

* Similar to `textContent` but reflects the visible content.

```js
div.innerText = "Visible only";
```

### 4.2 Changing Attributes

#### `setAttribute()`

* Sets a new attribute or changes the value of an existing one.

```js
img.setAttribute("src", "new-image.jpg");
```

#### `getAttribute()`

* Gets the current value of an attribute.

```js
const alt = img.getAttribute("alt");
```

### 4.3 Changing Styles Inline

* Modify element styles using the `style` property:

```js
button.style.backgroundColor = "blue";
button.style.fontSize = "18px";
```

### 4.4 Working with Class Names

#### `className`

* Sets or gets all class names as one string.

```js
div.className = "card highlight";
```

#### `classList`

* Recommended way to add/remove/toggle classes.

```js
div.classList.add("visible");
div.classList.remove("hidden");
div.classList.toggle("active");
```

### 4.5 Changing Element IDs

```js
div.id = "updated-id";
```



Use these methods to dynamically change your webpage's structure, style, or content based on user interaction or logic.

## 5. Creating and Removing Elements

### 5.1 Creating Elements

#### `document.createElement()`

* Creates a new element but doesn’t insert it yet.

```js
const newDiv = document.createElement("div");
newDiv.textContent = "I am new here!";
```

### 5.2 Appending Elements

#### `appendChild()`

* Appends a node as the last child.

```js
parent.appendChild(newDiv);
```

#### `append()` (modern)

* Can append multiple nodes or strings.

```js
parent.append("Some text", anotherElement);
```

#### `prepend()`

* Inserts a node at the beginning of the parent.

```js
parent.prepend(newDiv);
```

### 5.3 Inserting Elements at Specific Positions

#### `insertBefore()`

* Inserts a node before a reference node.

```js
parent.insertBefore(newDiv, existingChild);
```

### 5.4 Removing Elements

#### `removeChild()`

* Removes a child node from its parent.

```js
parent.removeChild(child);
```

#### `element.remove()` (modern)

* Removes the element directly.

```js
child.remove();
```

### 5.5 Replacing Elements

#### `replaceChild()`

* Replaces one child node with another.

```js
parent.replaceChild(newElement, oldElement);
```

---

Use these methods to dynamically construct or modify the page layout during runtime, such as adding user-generated content or interactive features.

## 6. Traversing the DOM

### 6.1 Parent Elements

#### `parentNode` and `parentElement`

* Both return the parent of a node.
* `parentElement` returns `null` if the parent is not an element.

```js
const parent = element.parentNode;
const parentEl = element.parentElement;
```

### 6.2 Child Elements

#### `childNodes`

* Returns all child nodes, including text, comments, etc.

```js
const allChildren = parent.childNodes;
```

#### `children`

* Returns only element children.

```js
const elementChildren = parent.children;
```

#### `firstChild` / `firstElementChild`

* `firstChild`: May return a text node (e.g., whitespace).
* `firstElementChild`: Returns the first child that is an element.

```js
const firstEl = parent.firstElementChild;
```

#### `lastChild` / `lastElementChild`

```js
const lastEl = parent.lastElementChild;
```

### 6.3 Sibling Elements

#### `nextSibling` / `nextElementSibling`

* `nextSibling`: May return a text node.
* `nextElementSibling`: Returns the next sibling that is an element.

```js
const nextEl = element.nextElementSibling;
```

#### `previousSibling` / `previousElementSibling`

```js
const prevEl = element.previousElementSibling;
```

### 6.4 Use Case Example

```js
const item = document.querySelector(".list-item");
console.log(item.parentElement);
console.log(item.nextElementSibling);
```



Traversing allows you to navigate and manipulate related elements in the DOM hierarchy.

## 7. Event Handling

### 7.1 What is an Event?

* An event is a signal that something has happened (e.g., click, keypress, form submit).
* JavaScript can respond to these events to create interactive behavior.

### 7.2 Adding Event Listeners

#### `addEventListener()`

* Attaches a handler to an event.

```js
const button = document.querySelector("button");
button.addEventListener("click", () => {
  alert("Button clicked!");
});
```

### 7.3 Common Event Types

* `click`
* `mouseover` / `mouseout`
* `keydown` / `keyup`
* `submit`
* `change`
* `input`

### 7.4 Accessing the Event Object

* The event handler receives an event object.

```js
button.addEventListener("click", function(event) {
  console.log(event.target); // element that was clicked
});
```

### 7.5 Prevent Default Behavior

* Used to stop the default action (like form submission).

```js
form.addEventListener("submit", function(e) {
  e.preventDefault();
  console.log("Form not submitted");
});
```

### 7.6 Removing Event Listeners

* Useful for cleanup or conditional interaction.

```js
function greet() {
  alert("Hi");
  button.removeEventListener("click", greet);
}
button.addEventListener("click", greet);
```



Event handling is essential for building responsive and interactive web pages by responding to user actions in real time.

## 8. Event Delegation

### 8.1 What is Event Delegation?

* A technique to handle events at a higher level in the DOM rather than on individual elements.
* Useful when you have many child elements or dynamically added elements.

### 8.2 How It Works

* Instead of attaching event listeners to each item, you attach one listener to a common parent.
* Use the `event.target` to detect which child was interacted with.

### 8.3 Example

```js
const list = document.getElementById("item-list");

list.addEventListener("click", function(e) {
  if (e.target && e.target.matches("li")) {
    console.log("Clicked on", e.target.textContent);
  }
});
```

### 8.4 Why Use Event Delegation?

* Performance: Fewer event listeners.
* Dynamic Elements: Works even for elements added later.

### 8.5 `event.target` vs `event.currentTarget`

* `event.target`: The actual element clicked.
* `event.currentTarget`: The element the listener is attached to.

### 8.6 Use Case: Dynamic Lists

```js
const ul = document.querySelector("ul");

ul.addEventListener("click", function(e) {
  if (e.target.tagName === "LI") {
    e.target.classList.toggle("selected");
  }
});
```



Event delegation improves scalability and efficiency, especially when working with dynamic or large DOM trees.

## 9. DOM Collections vs Arrays

### 9.1 DOM Collections Overview

DOM methods often return special types of collections:

* `HTMLCollection`
* `NodeList`

These are **array-like objects** but **not true arrays**.

### 9.2 HTMLCollection

* Returned by methods like `getElementsByClassName` or `getElementsByTagName`.
* Live collection: updates when DOM changes.
* Can be accessed by index or `for...of` loop.

```js
const divs = document.getElementsByTagName("div");
console.log(divs[0]);
```

### 9.3 NodeList

* Returned by `querySelectorAll()`.
* Static collection: does not update automatically.
* Supports `forEach()` method (unlike HTMLCollection).

```js
const items = document.querySelectorAll("li");
items.forEach(item => console.log(item.textContent));
```

### 9.4 Converting to Real Arrays

To use array methods like `map()`, `filter()`, etc., convert collections to arrays:

#### Method 1: `Array.from()`

```js
const arr = Array.from(document.querySelectorAll("p"));
arr.map(p => console.log(p.textContent));
```

#### Method 2: Spread Operator

```js
const arr = [...document.getElementsByClassName("box")];
arr.forEach(box => box.style.border = "1px solid black");
```

### 9.5 Summary Table

| Feature          | HTMLCollection | NodeList |
| ---------------- | -------------- | -------- |
| Live             | Yes            | No       |
| `forEach()`      | No             | Yes      |
| Index Access     | Yes            | Yes      |
| Convert to Array | Yes            | Yes      |



Understanding the difference between these collections helps avoid bugs when looping or manipulating DOM elements.

## 10. Practical Examples

### 10.1 Toggle Visibility of an Element

```html
<button id="toggle-btn">Toggle</button>
<div id="content">This is visible content.</div>
```

```js
const btn = document.getElementById("toggle-btn");
const content = document.getElementById("content");

btn.addEventListener("click", () => {
  content.classList.toggle("hidden");
});
```

### 10.2 Simple Form Validation

```html
<form id="login">
  <input id="email" type="email" required />
  <button type="submit">Login</button>
</form>
```

```js
const form = document.getElementById("login");

form.addEventListener("submit", function(e) {
  e.preventDefault();
  const email = document.getElementById("email").value;
  if (!email.includes("@")) {
    alert("Invalid email address");
  } else {
    alert("Form submitted");
  }
});
```

### 10.3 Create and Append List Items

```html
<ul id="task-list"></ul>
<button id="add-task">Add Task</button>
```

```js
const list = document.getElementById("task-list");
const btn = document.getElementById("add-task");

btn.addEventListener("click", () => {
  const li = document.createElement("li");
  li.textContent = "New Task";
  list.appendChild(li);
});
```

### 10.4 Accordion Toggle Example

```html
<h3 class="accordion">Section 1</h3>
<div class="panel">Content 1</div>
```

```js
const accordions = document.querySelectorAll(".accordion");

accordions.forEach(acc => {
  acc.addEventListener("click", () => {
    acc.nextElementSibling.classList.toggle("active");
  });
});
```

## ES6 Features (ECMAScript 2015)

### 1. `let` and `const`

* `let`: Block-scoped variable.
* `const`: Block-scoped, cannot be reassigned.

```js
let count = 5;
const name = "Alice";
```

### 2. Arrow Functions

* Shorter syntax for functions.

```js
const add = (a, b) => a + b;
```

### 3. Template Literals

* Use backticks (\`) for string interpolation.

```js
const name = "John";
console.log(`Hello, ${name}!`);
```

### 4. Default Parameters

* Assign default values to function parameters.

```js
function greet(name = "Guest") {
  console.log(`Hello, ${name}`);
}
```

### 5. Destructuring

* Extract values from arrays or objects.

```js
const [a, b] = [1, 2];
const {x, y} = {x: 10, y: 20};
```

### 6. Spread and Rest Operators

* `...` used to expand or collect values.

```js
const nums = [1, 2, 3];
const newNums = [...nums, 4];

function sum(...args) {
  return args.reduce((a, b) => a + b);
}
```

### 7. Enhanced Object Literals

* Shorthand for assigning properties.

```js
const name = "Tom";
const user = {
  name,
  greet() {
    return `Hi ${this.name}`;
  }
};
```

### 8. `for...of` Loop

* Iterates over iterable objects like arrays.

```js
for (const item of ["a", "b", "c"]) {
  console.log(item);
}
```

### 9. Promises

* Handle asynchronous operations.

```js
const fetchData = () => {
  return new Promise((resolve, reject) => {
    setTimeout(() => resolve("Done"), 1000);
  });
};

fetchData().then(console.log);
```

### 10. Modules (Import/Export)

* Organize code across files.

```js
// add.js
export const add = (a, b) => a + b;

// main.js
import { add } from './add.js';
console.log(add(2, 3));
```

---

These ES6 features improve code readability, maintainability, and modern JavaScript development practices.
